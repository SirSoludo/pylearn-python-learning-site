# PyLearn: Learn Python Programming

An interactive website for learning Python, one lesson at a time. It runs entirely in the browser, with no server or database: user accounts and progress are saved in the browser's `localStorage`.

## Features

- **Registration** and a personalised **dashboard** showing course progress and where to continue
- **Lessons** with detailed lesson pages
- **Quizzes** to test each topic
- **Python playground** for trying out code
- **Achievements** and a **progress** page
- Account deletion (clears all saved data)

## Run

Open `index.html` in any modern browser. No install or build step needed.

## Files

| Path | What it does |
|---|---|
| `index.html` | All pages/views (registration, dashboard, lessons, quiz, playground, achievements, progress) |
| `style.css` | Styling and layout |
| `script.js` | App logic: navigation between views, lesson and quiz content, scoring, saving user and progress data |
